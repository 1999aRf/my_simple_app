## Starting the project

### 1️⃣ Install dependencies
Before running, make sure you have Flutter installed.  
If Flutter is not installed, download it from [official website](https://flutter.dev/docs/get-started/install).

After installing Flutter, open a terminal and execute:
flutter pub get

### 2️⃣ Start the application
Start the emulator (or connect a physical device) and run:
flutter run

If you have multiple devices, you can select a specific one:
flutter devices
flutter run -d <device_id>

## Running tests

### 1️⃣ Run all tests
flutter test

### 2️⃣ Run a specific test
flutter test test/widget_test.dart
